# prompts design

## Overview

This repository is reserved for refined prompts used across agent command-line tools.

The first prompt covers code mapping, unused code, duplication, and dependencies.

## Colors

No palette, CSS token, ANSI style, or semantic color rule exists.

Editors, terminals, and GitHub control any syntax highlighting.

## Typography

Prompt files start with a descriptive level-one title and use ordinary Markdown sections.

The README indexes every prompt with a relative file link.

## Layout

Store one prompt per Markdown file under `prompts/`.

Use lowercase, hyphenated filenames. Use placeholders for private project details.

## Elevation & Depth

No visual elevation or content nesting system exists.

Do not define prompt hierarchy, inheritance, composition, or include behavior until tracked content implements it.

## Shapes

No logo, icon, border, container, delimiter, or prompt fence is defined.

Standard Markdown punctuation has no special prompt meaning in the current repository.

## Components

The collection has a Python checker and process tests, without a prompt runtime.

CI checks privacy patterns, Markdown hygiene, and index coverage. Human review checks identifying context.

## Do's and Don'ts

Do keep statements tied to tracked files.

Do update this document when the prompt format changes.

Do state unimplemented behavior as unimplemented.

Don't invent prompt names, roles, variables, frontmatter, examples, or evaluation results.

Don't claim compatibility with a model or agent without testing that prompt there.

Don't add a visual system, web route, or public application to this text collection.
